# 为 Check 结果与问题附带多语言文档引用

## 问题

Check 的文档虽已随 Bundle 发布，结果却只报告 problems；调用方需要知道索引约定并按 code 自行关联，单独传递结果或问题时也缺少解释入口。

## 结果

统一 Check 输出标准：关于检查的 documentation 直接放在 result 节点下，关于问题的 documentation 直接放在对应 problem 节点下。每处列出该 Check 声明支持的全部语言引用，调用方自行选择语言、按需读取正文。

## 边界

- 引用精确绑定本次执行的不可变文档版本，可独立解析；不把正文重复塞进结果。
- 公共机制自动装配引用，不要求各检查手写；不让通用 Engine 解释 problem code。
- 保持检查事实、执行故障与文档读取故障的区别；不扩大为旧 Checker/Objective Host 的复活或迁移。

## 验收标准

- 通过与未通过的 result 均有检查文档引用；每个 problem 有自己的问题文档引用。
- 每处引用覆盖全部声明语言，并能定位与执行版本一致的页面，无需调用方再按 code 查索引。
- 调用方可仅凭单独传递的节点选择语言并读取解释；文档不可用时明确报错，不改变检查结论。
