# Implementation

准备阶段的可调整种子，不是实施授权；范围见[构想](ideal/Idea.md)及[讨论依据](ideal/Discussion.md)。

## Steps

### I-S01: 收敛声明与迁移契约

获准实施后核对全部注册类型与历史绑定，落实已确认的 Schema、判等和兼容规则，明确动态 subject 及运行时检查的边界。

### I-S02: 接入共享机制与发现协议

按确认契约调整类型定义、生成式输入校验/判等及受控类型发现，迁移直接受影响的类型、例子和文档，不实现 UI 或资产管理。

### I-S03: 验证兼容与行为边界

补充直接相关的协议、Schema 和执行共享回归测试，运行 pnpm check，不把不支持的旧契约当成功。

## Acceptance criteria

### I-AC01: 声明与生成行为一致

以代表性有效/无效输入、对象与数组判等、默认值和复杂 Schema 测试证明唯一输入契约及明确错误；分别验证 Validate 的合法性检查与 Equals 的结构比较，覆盖额外字段和不符合 Schema 的比较输入，资源限制不被绕过。

### I-AC02: 发现结果可信且受控

以 HTTP 与注册配置测试证明实际类型、版本与 Schema 对应，授权隔离有效，不泄露凭据或依赖浏览器硬编码。

### I-AC03: 执行语义与迁移可复核

以幂等、历史恢复、Prepared 共享、取消和版本差异回归证明保留不变项及显式迁移行为；pnpm check 通过，文档对应候选。
