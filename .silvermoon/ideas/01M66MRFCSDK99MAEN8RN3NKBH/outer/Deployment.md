# Deployment

准备阶段的可调整种子；尚未实施或部署，不构成验收或发布授权。

## Steps

### D-S01: 准备独立消费环境

在明确拥有的临时目录和端口，通过打包产物组装代表性任务服务与独立消费者，不使用其他 session 的服务或数据库。

### D-S02: 验证公开契约闭环

从真实服务发现类型及 Schema，使用发现结果提交合法与非法输入，核对判等、共享和历史兼容的已确认规则；包含普通对象及 URL/digest 参数，不依赖资产查询或消费者自动下载制品，无需先实现浏览器 UI。

### D-S03: 记录结果并清理资源

记录准确候选与失败证据，仅回收验证拥有的进程、连接和临时文件；不发布 npm 包。

## Acceptance criteria

### D-AC01: 独立消费者可发现并使用契约

以打包消费及真实 HTTP 记录证明发现内容和实际接收行为一致，缺失/不支持/未授权场景明确失败；区分 Schema 非法输入的提交拒绝与业务一致性冲突的准备失败。

### D-AC02: 迁移与资源隔离可核验

以确认的旧数据场景和退出记录证明没有静默重解释历史绑定，验证未影响其他工作树、服务及数据。
