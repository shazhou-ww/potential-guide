# Deployment

## Steps

### D-S01: 验证独立消费者

在独立临时项目安装候选打包产物，按迁移文档运行 Pilot / Regulator 示例，不依赖仓库源码路径。

### D-S02: 验证真实进程与 HTTP 场景

使用可控 Agent 适配器、真实子进程和本地 HTTP 服务验证观测、修复重探测与取消边界；记录环境和结果，不将 npm 发布作为本 idea 的默认要求。

## Acceptance criteria

### D-AC01: 消费者能够复现

以独立项目运行记录证明公开入口与迁移说明足以构建和运行示例，无隐式仓库依赖。

### D-AC02: 效应边界在实际环境成立

以进程退出、HTTP 请求及 Agent 调用记录证明两类探针业务语义一致、取消不遗留本地资源、HTTP 取消未被误报为远端任务终止。
