# Deployment

在已交付 MVP 的基础上验证外部 Probe 消费，不包含正式发布或 Regulate。

## Steps

### D-S01: 运行独立 Objective 观察

在源码仓库外安装准确打包工具，启动注册 Check 与 Probe 的通用 Server，
以实际 Objective/Checker 制品经鉴权 HTTP/SSE 观察等级、问题、动态依赖与子 Check 证据。

### D-S02: 验证嵌套任务边界

使用受限资源配置验证并发父观察、共享子执行、取消、断线续接和服务重启，
记录准确版本与脱敏证据，确认未启动 Agent 并清理本次验证拥有的资源。

## Acceptance criteria

### D-AC01: 外部观察可复核

实际服务记录和准确制品摘要证明无需作者目录、旧 Objective Host 或修复 Agent 即可观察；
结果等级与问题符合夹具预期，子 Check 关联可通过授权历史读取。

### D-AC02: 受限容量下安全结束

真实并发实验在约定预算内完成或显式失败，不因父任务占槽永久等待；
取消不伤其他需求，恢复不悄悄重做原观察，清理确认后没有本次遗留子任务或进程。
