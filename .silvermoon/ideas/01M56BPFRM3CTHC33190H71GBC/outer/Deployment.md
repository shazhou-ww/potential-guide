# Deployment

## Steps

### D-S01: 准备真实 VS Code 验证环境

记录 VS Code、Agent Host 和 AHP 的实际版本及连接前提，使用用户已有授权与隔离测试目标；环境不可用时明确记录阻塞，不以替身冒充真实接入。

### D-S02: 实测修复与会话生命周期

在有限执行额度内验证真实 AHP 修复闭环、取消和恢复，补充一次现有 ACP 使用路径的对照验证，记录可复查且不含敏感信息的证据。

## Acceptance criteria

### D-AC01: 真实 AHP 修复达成目标

在已记录版本的 VS Code Agent Host 上完成隔离目标修复，证据包含真实会话身份和修复后的目标观察，不能只凭连接成功判为通过。

### D-AC02: 恢复与取消符合说明

实测记录能够证明恢复引用原会话、取消终止当前执行；不支持的能力或不可恢复情形按文档明确报告，不产生伪成功。

### D-AC03: ACP 路径仍可使用

在同一候选版本上完成 ACP 对照运行并保存结果，确认用户无需为新增 AHP 支持迁移原有可用配置。
