阅读约定

Objective 定义、声明和 Agent 资源使用已发布的 URI；内部记录和 CLI 响应仍保留各自现有数字版本。每页注明代码展示范围。

JSON Schema 面板的 $schema 声明方言，$id 标识该定义；业务实例的 $schema 则选择具体公共契约。运行时随包离线校验，不自动下载任意 URI。

TypeScript 类型可引用已安装的标准 schema 类型；简化切片明确标注，不冒充完整业务类型。内部格式需要校验，但不因此成为公共协议。
