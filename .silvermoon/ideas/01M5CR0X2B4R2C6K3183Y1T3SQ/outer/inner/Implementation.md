# Implementation

以下仅为可调整的实施初版，不代表已批准实施；具体变更以构想阶段逐项确认的规范为前提。

## Steps

### I-S01: 按确认的边界组织契约

在各自所属组件中整理已确认格式的定义、标识和解析入口，不将内部数据一律公开。主配置为所有扩展子命令保留独立定义自身配置的边界，不以核心全局配置类型枚举限制扩展。

### I-S02: 落实校验与兼容行为

按确认的规范实现结构与语义校验，更新生产者、消费者、测试及直接相关文档。

## Acceptance criteria

### I-AC01: 契约与归属一致

通过公共导出检查和针对性测试，证明每种已实现格式的标识、定义、校验入口符合已确认规范；用独立扩展子命令的配置样例证明新增自有 key 不需要修改主程序的全局配置类型。

### I-AC02: 兼容规则可验证

通过有效、无效、未知标识及旧格式用例验证确认的行为，相关检查通过且不存在未声明的格式变化。
