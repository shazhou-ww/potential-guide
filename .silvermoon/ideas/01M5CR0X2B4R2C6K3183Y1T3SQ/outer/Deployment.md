# Deployment

以下仅为可调整的外部验证初版，不授权发布 npm 包、部署公共服务或创建域名。

## Steps

### D-S01: 验证公共契约的独立消费

在确认的交付渠道中验证公共 schema 和文档可由独立消费者取得，并验证本地校验不依赖运行时联网。

### D-S02: 验证升级边界

使用确认的兼容样例验证消费者升级后的行为，明确公开承诺与内部数据的区别。

## Acceptance criteria

### D-AC01: 公共定义可取得且一致

独立消费证据表明确认的公共标识可取得对应定义，且与交付包的校验定义一致；具体渠道在规范确定后细化。

### D-AC02: 升级行为符合承诺

外部消费样例证明旧格式、未知格式和离线场景按确认的规则处理，不对内部格式产生额外公共兼容承诺。
