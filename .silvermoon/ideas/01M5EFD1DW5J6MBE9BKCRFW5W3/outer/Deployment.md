# Deployment

## Steps

### D-S01: 准备固定版本的隔离消费

固定已验收实现的提交，在独立消费环境中通过真实包或 Git Objective 加载入口验证，不借用源工作区文件。

### D-S02: 验证层级结果与迁移入口

从消费者入口验证 initial、部分达成、最高业务层级及旧契约处理，记录所用版本、命令和实际结果；不将单元测试冒充交付证据。

## Acceptance criteria

### D-AC01: 隔离消费者观察一致

固定版本的真实消费输出证明初始、部分达成和全部达成语义一致，不出现自动生成的 terminal；证据包含版本和可复现操作。

### D-AC02: 迁移行为可验证

隔离环境证明旧契约按文档显式迁移或清晰拒绝，现有证据不被静默重绑定。npm 发布及远程 schema 部署如有需要，须另行明确授权，不默认执行。
