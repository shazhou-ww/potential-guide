# Implementation

准备阶段的轻量初版；本轮仅创建跟踪，不进行全量术语替换。

## Steps

### I-S01: 建立术语与字段映射

梳理生命周期事件、日志、历史、订阅、页与游标的作用域，关联现有协议字段，
保留 revision 与 sequence 的独立语义。

### I-S02: 对齐契约措辞与示例

修订 axis 和直接关联的协议说明；通用表述须注明适用范围，
不由文档统一顺便改变 API 或运行行为。

## Acceptance criteria

### I-AC01: 术语含义明确一致

通过文档对照审阅证明同一术语没有冲突定义，生命周期与日志序号、分页及续接边界可区分。

### I-AC02: 示例与接口一致

核对示例、字段映射与现有公共类型，检查文档链接；不存在未授权字段重命名或行为修改。
