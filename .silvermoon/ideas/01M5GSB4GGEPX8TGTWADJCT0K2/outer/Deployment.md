# Deployment

## Steps

### D-S01: 固定版本隔离消费

在已验收实现范围内，通过独立安装的 CLI 和 PB 统一入口按需启动服务，运行多个真实 check、独立 probe 与同一 regulation 内连续观察，记录版本、进程身份及原始结果，不借用工作区模块。

### D-S02: 检验复用收益与故障回收

按顶层 CLI 调用范围比较首次与连续观察，证明 regulation 内 probe 复用已有服务，独立 probe 正常启停；验证目标变化、依赖交接、断开、取消及顶层结束后的回收，不以跨独立 CLI 共享作为验收前提。

## Acceptance criteria

### D-AC01: 真实消费证明复用

固定版本输出及进程证据证明 CLI 通过 PB 调度，regulation 内多次 probe 使用同一正确版本服务而不重复拉起；结果与问题归属不变，初始化减少且实际时延有可复现比较，不以源码测试替代公开入口。

### D-AC02: 失败与资源边界成立

外部操作记录证明变化后刷新、内层借用与顶层退出、依赖场景、超时及取消符合已确认契约，服务与来源/视图资源无误杀、提前释放、越界使用或失控残留。
