# Deployment

2026-10-24 按单 Objective npm 包及包 digest 身份重新准备；本轮不执行新部署。
原 [Consumption.md](./Consumption.md) 与 inventory 是旧版本消费证据，仍保留全部失败，
不证明新包边界或新身份已完成；D-* 因要求变化重置。不把既有实施验收当作新范围或发布授权。

## Steps

### D-S01: 固定版本隔离消费

从准确版本的干净源码构建并安装六个单 Objective npm 包，核验包名/唯一根 objective.yaml、
完整包 digest 与 check hash 映射。消费 registry/Git/tarball/local 的代表性实际来源，
其余标准 spec 以隔离 registry/本地 Git fixture 验证；不以字符串解析测试冒充获取。
registry fixture 不向真实 registry 发布；Git prepare/工具链只在显式授权准备时执行。
记录解析/构建来源与固定包字节，验证准确依赖闭包和断网恢复，不借用实时工作区模块。

独立安装 CLI、Host 和自包含产物，经真实 HTTP 执行双客户端、根检查依赖结果/上层处理和连续复用；
覆盖全部内置迁移入口，记录准确来源、消息与结果，不借用实时工作区模块。
对照公开内核的当前 CheckState 与 HTTP 状态投影，验证 Subject 原样传递及重复观察不重新执行。
通过开始、取消、观察单项及当前集合的公开接口验证，不使用临时替代设计或注册流程。
Windows 消费环境须具备受信 Windows PowerShell/.NET 权限后端；
在生成/写入 bearer token 前验证当前 SID 专属的受保护目录和文件 ACL，
后端不可用或遗留权限过宽时明确失败，不自动改写用户既有目录权限。

### D-S02: 检验复用收益与故障回收

同名不同来源、可变 tag/分支、本地编辑与内容篡改均验证固定边界：运行/continue/
Host 重启仍为原包，显式刷新才采用新包并重新观察；旧 Git 历史不静默重绑。
完成新包环境的真实冷/热 CLI 测量；保留原冷初始化超时和启动中退出的复现入口，
证明修复后的冷态与 shutdown，无预热或预算放宽的替代性结论。

比较冷/热延迟、线程初始化和长期资源占用；验证重复提交防护、观察断线/重新观察、取消、清理、
目录直接加载/同版复用、内容校验、排空更新与在途版本冲突、退役和预热。
无需调用注册或卸载 API；没有租约、事件恢复或视图 CRUD 验收要求。
不执行未授权发布、远程或生产变更。

## Acceptance criteria

### D-AC01: 真实消费证明复用

六包各自仅含一个 Objective，实际包名与 Coordinator 身份一致，完整包 digest 可重算；
registry 与非 registry 准备的准确内容可追溯，包内定义/资源/check 齐全，
恢复不依赖可变引用。以安装图、独立执行与 Coordinator 恢复记录证明。

多个 CLI 共用 Host endpoint，全部入口结果正确；依赖 check 完成后释放线程，
上层消费其业务要求、取得真实包级观察并重查，不经 Host 回调或跳过目标验证；
HTTP 从当前状态快照到后续变化正确反映同一执行，终态携带 CheckResult 或执行故障，
集合观察显示有权访问的活动任务及其离开，不重复执行或暴露其他任务的 Subject；
业务不通过（含依赖要求）不冒充调用故障，终态结果及证据正确保留；
目录/revision 的首次加载、连续复用和顺序更新均有真实证据；
线程复用减少初始化，跨 subject 证据不混淆，提供可复现的计数和时延比较。

### D-AC02: 失败与资源边界成立

准备端拒绝不可信脚本、错误包名、冲突来源和篡改；固定版本不可用明确失败，
不升级冒充恢复。首次冷启动与启动中 shutdown 的真实消费通过，旧失败有闭合证据；
无入库 bundle 的构建/pack 和完整 CLI 冷/热比较可复现。

实际观察连接中断不取消执行，重新观察同一 checkId 不透明重跑；
明确取消和单任务失败不误杀他人，终态有限保留及过期行为正确；
断流未收到终态时明确报告状态未知，不把连接断开写成远端 Cancelled；
清理完成后才复用，持续混合负载资源有界，退役/预热不突破额度；
旧协议明确拒绝，历史来源证据不重绑。
普通本机 Users/Authenticated Users/Everyone 不能读写 token 或替换 descriptor；
用实际 ACL/所有者与失败路径证明边界，不将 mode、umask 或当前用户可读当作隔离证明。
