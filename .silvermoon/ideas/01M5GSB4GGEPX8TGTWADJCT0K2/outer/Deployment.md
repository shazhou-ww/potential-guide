# Deployment

## Steps

### D-S01: 固定版本隔离消费

通过独立安装的多个 CLI、Pilot executable 和共享用户级注册，验证同一 Pilot ID 的同端口/单进程访问，不同 regulation object/subject 的 check 线程执行；记录版本、进程/线程及请求身份，不借用工作区模块。

### D-S02: 检验复用收益与故障回收

比较首次与连续调用，验证两个独立 CLI 的竞争启动和进程去重、版本冲突而不并存、单调用退出不影响另一调用、最后使用者后的回收，以及输入刷新、取消和旧协议拒绝；按确认后的机制执行，不预设租约或固定端口策略。

## Acceptance criteria

### D-AC01: 真实消费证明复用

固定版本公开入口证明多 CLI 对同 Pilot ID 只使用一个活动端口及进程，不同版本请求不触发多版本并存；实际执行来源准确，内部 check 线程处理不同对象/subject，输入与证据不混淆；计数覆盖线程初始化并比较时延。

### D-AC02: 失败与资源边界成立

外部记录证明共享服务的发现、失联、升级冲突、部分客户端退出、最后使用者回收及请求取消符合已确认契约；不误杀其他客户端，不提前释放来源/视图，不改写固定证据，旧协议明确拒绝。
