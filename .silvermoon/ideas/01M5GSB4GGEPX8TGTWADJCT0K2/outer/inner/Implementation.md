# Implementation

## Steps

### I-S01: 收敛协议与所有权

以 Pilot executable、HTTP/用户级共享注册及全量迁移为前提，定义按 Pilot ID 的端口发现和进程去重，版本不构成第二实例键。细化版本冲突/升级、共享使用权、启动/就绪、依赖回传及资源寿命，保留历史证据与旧输入拒绝边界；未决机制收敛后再实现。

### I-S02: 接通服务调度与真实检查器

为每个 Pilot 定义 executable，多个 CLI 经共享注册协调启动、发现和使用同 ID 的唯一活动进程；不同请求版本不能另起实例或静默替换执行版本。Pilot 管理有界 check 队列/线程，逐请求隔离不同 regulation object/subject；单个调用释放不关闭他人使用的服务。全量迁移内置 Objective、脚手架、示例、测试、生成物和消费面，不保留旧运行协议。

### I-S03: 验证失败边界与收益

覆盖启动、重复请求、依赖调度、超时取消、变化后重观察、来源与资源回收；执行针对性测试、冷/热计数比较及 pnpm check，更新直接相关文档。

## Acceptance criteria

### I-AC01: 多请求复用且观察独立

测试与真实计数证明两个独立 CLI 并发请求同 ID 时只发现一个活动端口和进程，不因版本/配置不匹配多开实例；Pilot 内部 check 线程处理不同对象/subject，请求证据独立，变化后刷新输入且层级顺序正确。

### I-AC02: 生命周期和失败有界

反例覆盖按 ID 竞争启动、版本冲突和顺序切换、旧注册/端口复用、多客户端退出及线程容量/依赖/取消；共享使用权和最后回收遵守已确认契约，不误杀活动请求、不静默重放或版本重绑。

### I-AC03: 校验和性能证据完整

相关测试、生成物及 pnpm check 通过，旧协议明确拒绝且历史契约未改写；固定输入对比同时统计进程/线程启动、每线程初始化及实际时延，证明重复工作减少，不以新建线程反复重载、跳检查或放宽预算替代。
