# Deployment

本轮计划交付可安装的权限支持，不包含 npm 发布、远端生产部署或扩大本机默认权限。

具体安装及真实验证范围见 [权限支持交付验证](./Verification.md)。

## Steps

### D-S01: 验证安装后授权行为

对独立安装产物验证明确拒绝、授权受阻返回及受限授权后的恢复，避免源码入口与安装入口行为不同。

### D-S02: 验证真实 ACP 有界执行

使用已认证且用户授权的真实 ACP Agent，在隔离目录中验证权限事件和允许范围；仅有限请求，不批准任意 shell 或整个设备访问。

## Acceptance criteria

### D-AC01: 安装产物保持权限边界

安装验证命令通过，拒绝和恢复场景有可追溯结果；配置不依赖开发者机器的隐式全量授权。

### D-AC02: 真实权限交互有证据

真实 Agent 的拒绝/授权及有限执行有证据，临时资源已清理。若账号或环境阻塞，明确记录并保持未验收，不使用测试替身冒充真实成功。
