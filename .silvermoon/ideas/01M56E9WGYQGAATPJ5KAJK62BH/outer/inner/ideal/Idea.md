# 支持单次调节权限与授权受阻返回

## 问题

regulation 已有 quota，但权限尚未作为完整执行约束贯穿配置与调度。真实 ACP 执行因权限不足无法推进时，可能耗尽额度并以同样权限重复续跑。

## 结果

一次 run 同时具有资源额度和显式授权范围；无法在现有授权内继续时正常返回 authorization-required，携带结构化申请及最后可信观测，供上层审批或重新规划。

## 边界

- 用户或管理员规定上限，coordinator 仅在上限内分配，regulator/ACP adapter 执行；planner 和 Agent 只能申请，不能自批。
- 默认拒绝未知权限，明确匹配时优先允许一次；ACP 不是操作系统沙箱，不以 cwd 或命令前缀证明任意 shell 安全。
- 保留 exhausted 的额度语义；一次权限拒绝不必终止有替代路径的 run。不自动提权、永久授权或开放所有工具，不在本构想中改写 setup 的内容校验标准。

## 验收标准

- 权限范围与 quota 独立、显式且不可越过上限；越界请求不得执行，拒绝原因可观察。
- 正常返回增加 authorization-required，不伪装成 exhausted 或 crash，申请包含操作、资源、原因及最后可信观测，无秘密泄露。
- 授权受阻后不以相同授权和执行计划自动续跑；只有有效授权变化或不再需要该权限的计划更新才能重新调度，并重新观测。
