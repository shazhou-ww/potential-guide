# 验证外部消费者的周期请求闭环

本文为准备阶段的现实世界验证初版；实际验证环境与证据在部署阶段细化，不代表已经执行。依据为[构想](./inner/ideal/Idea.md)。

## Steps

### D-S01: 准备独立消费者

使用实施完成后的公共包构建隔离的 Host 与监听消费者，固定实际版本、资源与有限执行额度，不依赖仓库源码映射；无需 npm 发布或真实付费 Agent。

### D-S02: 演练追加投入与恢复

在独立进程中观察周期派发、耗尽事件重读与一次性追加请求，实际重启 Host 并停止周期链；保存请求、Run、事件游标及资源占用证据。

## Acceptance criteria

### D-AC01: 外部可用且无需内置规划者

由独立消费者命令及类型检查证明，通过公共 API 可提交普通与周期请求、读取后继及耗尽事实，不需要 Portfolio Planner 或内置上层 Agent。

### D-AC02: 追加决策与恢复有真实证据

由跨进程记录证明上层重读事件后可幂等追加一次性请求，原周期链仍在；重启不重复派发或补充额度，显式停止后不再启动未来周期工作，同 Target 未发生重叠执行。
