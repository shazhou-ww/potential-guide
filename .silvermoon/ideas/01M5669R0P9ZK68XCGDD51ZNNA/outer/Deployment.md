# Deployment

本次交付优先为独立本机自查 Objective；以下为准备阶段的高层交付计划，不发布 npm、不连接未指定远端，也不将远程整备接入列为本轮交付要求。

此前交付结果见 [历史交付证据](./Verification.md)，不是新独立自查的交付证据。

## Steps

### D-S01: 同步并验证子目录交付

将已验收实现同步到 primary，使用精确 commit 的 Git 子目录 URI 加载并验证独立本机自查 Objective。

### D-S02: 验证目标用户的本机自查

在明确指定的本机用户环境中，用已安装的 pguide 运行已交付自查及真实隔离任务，记录版本、配置上下文、结果和限制，不代称远端已就绪。

## Acceptance criteria

### D-AC01: Git 子目录可用

已提交的独立本机自查可从固定 Git URI 加载，引用与执行路由正确，提交可从 primary 到达，以交付加载验证证明。

### D-AC02: 真实交付自查通过

目标用户的已安装 pguide 对已交付版本运行自查达到 terminal，并有真实隔离任务证据；文档说明后续 A 应调用 B 的同一自查，不宣称本轮已完成远端整备接入。
