# Implementation

具体接口、测试结果及验收边界见 [实现验收证据](./Verification.md)。

## Steps

### I-S01: 定义设备就绪观测与引导

在 objectives 下定义 setup Pilot、subject、等级、声明问题及对应文档；外部 Agent 可按文档引导安装和配置，优先检查自身 ACP 可用性。

### I-S02: 实现有界检查与真实 sanity

检查安装、配置及 ACP 接入；通过隔离的测试 Objective 驱动已配置 Agent 实际修改，再独立检查结果。所有进程、输出和清理都有边界。

### I-S03: 验证并接入仓库检查

补充通过、失败、拒绝授权、协议错误及清理测试，接入现有检查入口，同步用户文档。

## Acceptance criteria

### I-AC01: 定义可加载且指引完整

Pilot 校验通过，问题引用完整，文档包含 bootstrap、自身优先、凭据边界与运行示例。

### I-AC02: 就绪必须有实际证据

自动测试证明安装或配置缺失会失败、ACP 不可用会失败、Agent 空报完成不会通过、真实有限修复可通过，并确认临时资源清理。

### I-AC03: 仓库行为保持一致

pnpm check 通过，新增测试纳入默认测试入口，不引入运行时第三方依赖或无关重构。
