# Deployment

仅在操作拥有的隔离测试目标上验证授权修复，不使用真实业务资源或扩展凭据权限。
独立消费者验证不等于 npm 发布或生产启用。

## Steps

### D-S01: 运行独立治理闭环

在源码仓库外安装准确打包工具，以受控 Agent 和明确授权启动注册三类 Task 的服务，
经真实 HTTP/SSE 执行观察、修复、再观察，记录准确制品、任务关联和最终目标证据。

### D-S02: 验证拒绝与未知执行

对隔离目标验证拒绝授权、耗尽、依赖交接、重复提交、并发与取消，
在修复期间终止并重启服务，观察外部副作用计数及任务历史；清理本次进程、数据与测试目标。

## Acceptance criteria

### D-AC01: 授权治理结果可复核

从真实操作记录和新 Probe 结果证明目标实际达成，不依赖 Agent 自报成功；
拒绝、耗尽和依赖交接场景可从公开结果区分，未授权目标没有被修改。

### D-AC02: 取消与恢复不重复修复

外部副作用计数与恢复历史证明同幂等请求、重连和未知执行恢复不自动重复修复；
退出已确认时无本次遗留执行器，未确认时显式报告，不承诺副作用回滚或 exactly-once。
