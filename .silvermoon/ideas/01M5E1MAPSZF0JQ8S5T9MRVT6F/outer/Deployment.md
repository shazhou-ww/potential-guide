# Deployment

## Steps

### D-S01: 验证安装后的阅读与脚本体验

按现有分包安装方式在隔离目录使用候选包，检查 pguide 分派与独立命令的人类输出、非 TTY 重定向及 JSON 管道；只用合成配置和安全 fixture，不操作真实 Agent 或用户配置。

### D-S02: 说明兼容边界

向使用者说明人类输出改进和脚本显式选择 JSON 的方式。若需要发布，遵循现有分包发布流程并另行获得发布授权，本 idea 不授权 npm 发布。

## Acceptance criteria

### D-AC01: 安装产物行为符合约定

用候选安装产物复现 objectives list/show 等代表性场景，保留合成样例输出和执行结果，证明默认可读、JSON 可解析，主入口与独立命令一致。

### D-AC02: 使用者可识别兼容边界

可交付说明明确人类输出是展示层、机器消费者应选择 `--format json`，并列出配置原值、补全脚本和元数据等例外；以说明和安装验证记录为证据。
