# 统一 CLI 输出格式与内容

## 问题

CLI 存在对象直出、静默成功、诊断与执行信息缺失、帮助过时及错误风格不一致。已通过 421 次有效调用形成[完整审计](./output-audit.md)及带具体输出的[24 项问题](./output-findings.md)。

## 结果

统一全部自有 CLI 的展示格式、内容层级和消费约定，让用户直接判断结果、定位原因并知道下一步，同时保留机器和原文出口。方向见[输出规范](./output-conventions.md)。

## 边界

- 覆盖 pguide 主入口、独立命令、迁移器和协议出口；不强改第三方扩展，不在准备阶段修改实现。
- 保留业务语义、脱敏及机器契约；流、错误类别、退出码或参数行为若需调整，先明确兼容方案。
- 配置原值、补全脚本、元数据、固定协议和报告文件不是一律美化的对象。

## 验收标准

- 逐项解决或明确处置审计问题，列表、详情、回执、诊断、执行、帮助和错误符合统一内容约定。
- 默认及 Markdown 可读，JSON 成功/失败均可独立消费；原文和协议例外有明确契约。
- 以实测矩阵验证主入口和独立入口、成功/空态/错误，证明内容完整与兼容，而非只检查“不再输出 JSON”。
