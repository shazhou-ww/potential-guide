# 统一 pguide 面向人的默认输出

## 问题

`pguide objectives list/show` 虽默认选择 Markdown，却直接打印 JSON；其他命令还存在原始 YAML 直出或摘要不足，用户难以快速判断结果。详见[命令审计](./output-audit.md)。

## 结果

让默认输出和显式 Markdown 都优先服务人类阅读：列表便于扫描、详情分层、异常和下一步清晰；显式 JSON 继续服务脚本。

## 边界

- 覆盖内置命令和仓库维护的命令扩展，不强改第三方扩展。
- 不改变命令业务语义、退出码、脱敏或机器输出契约；保留配置原文、补全脚本等合理例外。
- 本 idea 统一规划优化，不在准备阶段修改实现。

## 验收标准

- `objectives list/show` 默认及显式 Markdown 不再整段倾倒 JSON，正常、空列表和歧义场景均有清晰呈现。
- 审计中的其他命令有一致且足以支持判断的摘要、详情及空态；合理例外有明确说明。
- 自动化证明默认与显式 Markdown 一致、JSON 可独立解析且字段契约不变，并覆盖主入口与独立命令。
