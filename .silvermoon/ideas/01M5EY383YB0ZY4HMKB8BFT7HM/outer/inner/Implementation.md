# Implementation

## Steps

### I-S01: 明确预算与诊断

对齐来源准备、整体观察与 check 超时配置、错误分类和分阶段计时，建立可重复的基线。

### I-S02: 减少同轮重复工作

先明确目标可变性与观察生命周期，再减少重复依赖观察和公共事实采集；保留来源证据、完整观察与独立包入口。根据测量再决定是否需要 worker 或全局有界并发，不预先引入复杂框架。

### I-S03: 验证收益与行为边界

运行针对性正确性、超时与取消测试，比较同输入的冷、热运行计数与耗时；更新直接相关说明并执行 pnpm check。

## Acceptance criteria

### I-AC01: 预算和错误可定位

测试证明三类预算各自生效，配置入口一致；超时携带可识别原因和阶段，取消清理不泄漏进程。

### I-AC02: 减少重复且不复用失效证据

计数与前后对比证明重复工作和耗时减少；反例证明变化、修复、新轮次及异常不产生旧结果命中，current、问题归属和固定来源保持正确。

### I-AC03: 校验与说明完整

针对性测试、生成物检查及 pnpm check 通过，直接相关文档说明生命周期、预算及性能测量边界。
