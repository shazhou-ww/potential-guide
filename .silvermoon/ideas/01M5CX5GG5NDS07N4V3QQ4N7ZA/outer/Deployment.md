# Deployment

以下为外部消费验证种子，不授权 npm 发布或改写用户真实 Agent 配置。

## Steps

### D-S01: 验证独立安装后的管理入口

在独立消费环境中验证 pguide agents 的发现、帮助、资源位置与管理行为，不依赖仓库源码或偶然 PATH。

### D-S02: 验证迁移与执行衔接

使用隔离的用户/项目配置样例，演示显式迁移后诊断及治理按正确名称和来源消费 Agent。

## Acceptance criteria

### D-AC01: 新入口独立可用

交付环境证据证明约定命令可发现且操作独立定义，类型与 schema 可取得；主配置语法不被本项暗中改变。

### D-AC02: 迁移后的来源与边界保持

外部样例证明旧内嵌格式明确拒绝、迁移后有效定义一致、秘密不出现在输出中，不通过文件移动扩大信任。
