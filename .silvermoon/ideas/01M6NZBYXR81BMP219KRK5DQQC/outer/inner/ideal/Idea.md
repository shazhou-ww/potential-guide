# 迁移环境检查脚手架并提取共享 Check 包

## 问题

`check-environment` 已交付 Task Engine 可执行的三个 Bundle，但仍手动生成声明并调用低层构建接口，未采用最新 `task-bundle init` 作者流程。结果契约和回调适配等公共代码仍局限在包内，未来新增检查容易重复实现或产生格式分歧。

## 结果

让环境检查使用标准脚手架、类型化契约和显式 `runTask` 入口构建交付，保持现有检查行为；将公共代码提取为独立 Check 包，供环境检查和未来的新检查复用。

## 边界

- 保留 tools、directories、network 三个独立 Bundle、现有库 API 与结果格式。
- 不恢复旧 Check Host，不修改通用 Engine 协议，不增加另一套专属构建流程。
- 独立共享包承载统一结果契约和回调适配，不承载环境检查算法、资源调度或构建发布流程。

## 验收标准

- 三个检查可通过最新作者流程构建 CAR，并由 Task Engine 按 CID 执行。
- 通过、发现问题、执行故障和取消行为保持兼容，现有 Objective 库消费者不受影响。
- 环境检查实际使用独立共享包；用新的最小检查证明无需复制公共代码即可接入标准脚手架和 `runTask`。
