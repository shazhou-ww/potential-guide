# Deployment

本契约是准备阶段的现实验证初版；不要求发布 npm 包。

## Steps

### D-S01: 观察主分支 CI 的完整结果

在实施候选同步主分支后，核验实际 CI 的 Node 版本检查、打包消费者与跨平台 CLI 验证结果及其运行记录。

### D-S02: 核验日常反馈与完整验证收益

在可比较的真实开发环境和 CI 中观察完整检查，区分冷启动与缓存命中；核验新入口可用、检查覆盖映射成立，并保留对照证据。

## Acceptance criteria

### D-AC01: 交付保障在真实 CI 中通过

提供绑定候选提交的成功运行链接，证明 Node 兼容性、完整消费者验证和必要的跨平台 CLI 安装运行保障未丢失。

### D-AC02: 实际性能收益与入口可验证

提供完整成功的真实运行对照，证明达到实施阶段明确的性能目标；开发者按文档可执行默认检查和完整验证，不依赖未记录的本地状态。
