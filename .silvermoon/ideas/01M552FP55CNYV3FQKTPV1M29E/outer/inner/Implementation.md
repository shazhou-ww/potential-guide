# Implementation

主要修改两个领域包，并在必要处联动 CLI、配置和 Pilot 的依赖描述。

## Steps

### I-S01: 收敛单次调节契约

移除周期调度配置，引入每次 run 的 quota 与三类正常结果，明确前置、故障和取消边界，保留多轮修复。

### I-S02: 建立规划与协调闭环

定义目标组合、优先队列及事件接口，提供可替换 planner 和 ACP MVP 接入；实现资源感知、续跑、P0、生命周期及共享前置反馈。

### I-S03: 集成入口与验证

迁移配置和命令入口，补全相关文档与回归测试，通过 pnpm check；主会话检查接口一致性及端到端路径。

## Acceptance criteria

### I-AC01: 单次调节结果可验证

自动测试证明多轮达标、quota 耗尽、前置不满足时零越界修复、输入错误、执行异常和取消均遵循约定。

### I-AC02: 规划调度职责可验证

自动测试证明队列更新、共享前置、资源上限、普通非抢占、P0 抢占及升级通知、终止后释放资源、完成不盲目重跑和 exhausted 续跑。

### I-AC03: 集成一致且兼容迁移明确

ACP 测试替身通过真实协议驱动规划与执行，CLI/config 明确拒绝旧调度字段，pnpm check 通过且相关文档同步。
