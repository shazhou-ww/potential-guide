# Deployment

## Steps

### D-S01: 固定独立消费候选

在部署阶段固定 SDK、Engine、工作台与示例 bundle 的准确候选版本和配置；按项目授权准备独立消费环境，不默认发布 npm。

### D-S02: 演练实际日志查看

在独立 Task Server 与工作台提交示例 bundle，验证执行中、结束后及重新连接后的日志查看与精简业务结果。

### D-S03: 核验运行策略

在实际环境核验日志容量、保留、权限及超限行为，记录结果和已知限制，确认操作者可识别诊断信息的不完整性。

## Acceptance criteria

### D-AC01: 独立消费者可使用

以固定候选和独立安装/运行记录证明：任务作者与操作者无需源码工作区即可输出、查看日志。

### D-AC02: 工作台体验符合预期

用实际 Run 的查询记录和工作台演练证明：实时、历史、并发及重新连接场景可用，Result 不混入 verbose 信息。

### D-AC03: 策略与限制可观察

用实际容量、权限和保留策略演练证明：未授权调用不能读取日志，超限及过期状态明确可见，系统资源没有无界增长。
