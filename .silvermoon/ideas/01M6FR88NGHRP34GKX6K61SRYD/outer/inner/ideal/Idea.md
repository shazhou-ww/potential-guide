# 为 Task Run 提供独立诊断日志通道

## 问题

Task 执行中的 verbose 信息没有可按 Run 查看、追溯的专用通道，容易被塞入 Result 或 progress。Worker stderr 也不是任务历史的一部分。

## 结果

任务作者可以输出独立诊断日志，调用方可以在执行中及结束后按 Run 查看；check 的业务结果仍只表达是否通过及实际问题。

## 边界

- 日志不替代 Result、progress 或 checkpoint，不参与任务匹配、复用与终结判断。
- 输出与保留必须有界；超限、截断或不可用必须可见，不能无限增长或伪装完整。
- 不扩展为交互终端，也不默认转发凭据、环境变量或任意子进程输出。

## 验收标准

- 同一任务能产生独立日志和精简 Result，二者不会混淆。
- 工作台能按 Run 查看实时与历史日志，并区分并发 Run 的输出。
- 成功、失败、取消及超限场景的日志可用性清晰，原有任务生命周期语义不变。
