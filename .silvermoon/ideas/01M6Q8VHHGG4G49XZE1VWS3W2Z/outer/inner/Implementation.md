# Implementation

## Steps

### I-S01: 确认最小整改集合

依据理想世界的问题清单，区分仓库可改进项、外部服务能力和操作规范；在实施前确认本轮范围，不默认修复全部问题。

### I-S02: 落实整改与针对性回归

仅针对确认范围修改相关代码、工具或文档，保留失败场景及防止误报的回归检查。

## Acceptance criteria

### I-AC01: 改动可映射到问题编号

每项改动对应已确认问题、原始失败证据和预期行为；未处理项保留明确状态，不用测试重试代替修复结论。

### I-AC02: 证明不削弱既有约束

针对性回归证明不降低制品身份、结果严格性、资源回收或认证隔离要求；仓库改动通过现有适用检查。
