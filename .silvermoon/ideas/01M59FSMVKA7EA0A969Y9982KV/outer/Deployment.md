# Deployment

本文件仅为现实验证种子，不表示当前开始执行，不授权发布或带费用的 Agent 调用。

## Steps

### D-S01: 准备版本确定的独立消费环境

固定源码与交付产物，准备不依赖开发工作树隐含文件的环境，按各 Pilot 的实际加载方式验证资源和运行时供应。

### D-S02: 逐个验证真实 Pilot 入口

经真实 pguide 加载、发现和 process probes 验证各正式 Pilot 的正反例及适用的修复闭环；涉及远程设备、Agent、费用或权限时先满足既有授权条件。

### D-S03: 核验入口迁移与外部证据

核验历史入口兼容或迁移说明可执行，记录准确版本、结果与限制；不得因 package 化宣称线上部署、npm 发布或真实身份资源已经验证。

## Acceptance criteria

### D-AC01: 交付单元可以独立消费

每个 Pilot 在声明的消费方式下可定位正确 manifest、References、执行入口和依赖；以隔离消费实测证明不借用旧 Objectives 主体或开发机偶然路径。

### D-AC02: 各 Pilot 的真实行为保持

真实调用证据覆盖各 Pilot 的有效与无效输入、检查顺序和适用终态；有副作用的行为须遵守原有同意、权限、预算及清理边界，未授权验证不得记为通过。

### D-AC03: 迁移与限制可复查

准确版本、调用路径、兼容/迁移结果和未验证边界均可复查；观察操作不产生合同以外的目标修改，不执行未经授权的发布、部署或设备整备。
