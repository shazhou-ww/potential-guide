# Deployment

这是准备阶段的外部验证种子，不是部署完成报告。
通过独立消费者验证打包交付，不要求发布 npm 包或运行常驻生产服务器。

## Steps

### D-S01: 验证独立进程内消费者

在仓库外安装打包产物，用独立的非制品任务类型装配引擎，
不启动 HTTP 也能完成提交、观察、结果读取与取消。

### D-S02: 验证宿主挂载与恢复

由测试宿主自行监听端口并挂载适配器，使用公开协议调用；
验证身份隔离、错误、订阅断连和真实进程重启下的查询/取消/递归语义。

### D-S03: 形成可复核交付证据

保存产物摘要、场景输入与脱敏结果，说明未覆盖限制；
停止操作拥有的服务并清理临时资源，不发布、不合并、不标记来源 idea 已完成适配。

## Acceptance criteria

### D-AC01: 核心可独立嵌入

安装消费者无需引用仓库源码或具体制品业务，即可运行公开 API；
报告可证明不存在自动监听端口或强制 HTTP 往返。

### D-AC02: 外部行为与契约一致

独立客户端复核内驱 stage、canceledAt 与时间条件的独立投影、类型冲突、共享需求隔离、
原节拍递归、历史读取与重启边界，结果与进程内语义一致。
验证时间到点不虚构阶段转移；调用方到期放弃等待后仍可查询未取消任务的迟到完成，
结果同时保持超时判断，不把时间失约等同于没有结果。

### D-AC03: 证据完整且资源收束

摘要与已安装产物一致，故障和限制如实记录；
验证后进程退出、端口释放，不遗留凭据或未授权发布动作。
