# Deployment

## Steps

### D-S01: 在隔离消费环境试装

使用实施阶段对应版本的打包产物，在仓库外按用户文档试装最小主包、代表性命令组合和独立协议消费者；验证不依赖工作区链接。这里的仓库外试装不是迁移源码或 Objective 仓库；公开发布需另获授权，不在本构想中自动执行。

### D-S02: 验证真实使用与迁移

在 Windows 和 POSIX 消费环境验证命令发现、独立入口及代表性业务流程，按迁移说明演练原整体安装的升级路径，并保存环境与命令证据。

## Acceptance criteria

### D-AC01: 按需消费可复现

仓库外试装记录包含产物版本、安装命令及依赖清单，证明最小主包不带入全部业务包，所选命令能够被发现和调用；独立协议消费者可使用 Pilot 定义、schema 与校验，不要求安装上层执行或 CLI 包。

### D-AC02: 跨平台迁移可验证

Windows 与 POSIX 的执行记录证明两种入口、未安装提示和迁移步骤符合文档；证据关联实际试装产物，不能仅以源码测试代替。
