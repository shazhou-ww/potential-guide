# Deployment

## Steps

### D-S01: 准备真实组合与文档场景

交付一个组合多个 Check 的候选 Objective，包含默认继承和场景化 References，在独立消费者环境使用。

### D-S02: 验证业务入口与恢复

通过公开 CLI 或 API 验证观察、指导及受控 regulation，并恢复同一任务；隔离外部 Agent 权限和业务副作用。

## Acceptance criteria

### D-AC01: 使用者获得正确等级与指导

记录实际 subject、Check 制品摘要、等级结果和引用页面，证明未覆盖说明继承、覆盖内容仅在目标场景生效。

### D-AC02: 恢复不漂移

记录原任务与恢复任务的准确来源和摘要，验证远端替换或缺失时不会静默升级或回退。
