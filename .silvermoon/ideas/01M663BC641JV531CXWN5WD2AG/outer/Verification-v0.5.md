| 场景 | 本轮证据 |
| --- | --- |

| 新建 Popup | 原生鼠标打开，Escape 关闭后焦点回新建按钮；切 Tab、关闭重开后保留同一个输入节点和值。提交成功关闭弹窗并选中 Task。 |

## 生命周期、隔离与保留

- UI 单独停止/更新期间，新后端及已有任务、收藏继续保留；原用户 UI `62952` 和后端 `61109` 未重启、未清理。新旧 UI 都再次以 HTTP 200 核验可用。
- 关闭 UI 不取消任务的真实 HTTP 回归及第一轮双进程运行任务验证继续有效，本轮没有修改调度或关闭语义；新增目录同样不启动或拥有执行器。
- 所有自动验证仅使用主 Agent 创建的新 Chrome 页，结束后关闭这些页并清除其设备模拟；没有关闭用户 Chrome 或原试用页。
- 两个版本的用户试用服务属于明确保留的资源，不声称已停止。新版登记为 `ui-v05-trial-backend` / `ui-v05-user-frontend`，旧版为 `ui-user-trial-backend` / `ui-user-trial-frontend`；均使用独立 fixture 目录，等待用户结束试用后按这些准确句柄清理。
