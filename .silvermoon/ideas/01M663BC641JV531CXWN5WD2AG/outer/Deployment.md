# Deployment

准备阶段的轻量种子；尚未实施或部署，不构成验收。进入相应阶段后再细化验证环境与证据。

## Steps

### D-S01: 准备独立真实验证环境

在明确拥有的临时资源上启动不同端口的 UI 与通用 Task Server，不复用或改动其他会话服务，不发布 npm 包。

### D-S02: 验证浏览器调试流程

对真实服务执行获准故事与故障恢复，覆盖任务操作/调度观察、类型资产、收藏及历史重做；进行浏览器实测和截图检查，验证中文、键盘操作与窄屏布局。资产清理仅使用验证环境拥有的缓存。

### D-S03: 验证生命周期并清理

确认无 UI 与 UI 退出时后端任务仍可运行，随后仅清理本次验证拥有的进程、连接与临时资源。

## Acceptance criteria

### D-AC01: 服务分离与任务独立

以进程、监听端口及 UI 停止前后的后端查询证据证明独立运行；UI 关闭不取消任务。

### D-AC02: 真实用例可操作

以真实服务观察及浏览器截图证明需求确认稿中的获准故事和补齐规则有效，包括资产版本、受限清理、收藏与历史重做；新通用类型不要求 UI 硬编码其输入。

### D-AC03: 验证隔离且资源可回收

以验证资源清单与退出检查证明只清理自身资源，其他 checkout、会话工作树与既有服务不受影响。
