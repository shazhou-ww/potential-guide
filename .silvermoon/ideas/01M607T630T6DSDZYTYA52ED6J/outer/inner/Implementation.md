# Implementation

## Steps

### I-S01: 明确 Check 制品契约

定义 manifest、Check/problem 身份、References、运行资源与内容摘要的边界，复用现有 Host 契约及安全校验。具体字段和格式版本在实施阶段确定。

### I-S02: 打通构建与准备执行

实现显式打包、本地及 HTTPS 获取、摘要校验和不可变缓存，将已准备目录交给 Host；不运行安装脚本或隐式构建。

### I-S03: 补齐验证与开发说明

用真实 Check 覆盖打包、消费和异常路径，更新直接相关文档，确认既有 Host 行为不退化。

## Acceptance criteria

### I-AC01: 独立制品可执行

集成测试从源码构建制品，并在不安装 Check 依赖的环境验证结果、执行资源与 References 完整。

### I-AC02: 内容与提取边界可验证

测试覆盖摘要不符、内容缺失、路径穿越、链接和大小超限；缓存不得接受不同内容冒充同一摘要。

### I-AC03: Host 语义保持一致

相关现有与新增测试验证预算、取消、结果和清理；项目要求的相关构建、类型及检查命令通过。
