# 让状态树测试同时驱动自动验证与人工操作手册

## 问题

树形 E2E 已能表达状态与转移，但阅读自动化函数不足以指导人工复验，
另写手册又容易与测试路径脱节。

## 结果

以固定 YAML 统一描述 state、transition、检查条件及人工说明，
按函数 ID 绑定实现；同一数据既驱动自动测试，也生成可逐步执行的人工手册。

## 边界

- YAML 是结构与说明的唯一来源；不维护第二棵手写 BDD 树，不在数据中放可执行脚本。
- transition 调用时进入状态并返回 after 负责收尾；文档生成不加载测试实现或启动服务。
- 先以 Check Host 验证；Node Test 是执行适配，不新增依赖式测试调度，清理不是业务状态回滚。

## 验收标准

1. 同一 YAML 可生成或展开 Node Test 测试，并输出终端树、Markdown 及可离线查阅的 HTML。
2. 人工手册按路径展示 transition 的进入操作、当前 state 的探针及逆序 after；包含故障路径及平台限制。
3. 非法数据及执行入口的未知绑定明确失败；部分初始化或清理失败不跳过其他应执行的收尾、不掩盖原始错误，人工可依手册复验代表路径。
