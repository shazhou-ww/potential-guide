# 让状态树测试同时驱动自动验证与人工操作手册

## 问题

树形 E2E 已能表达状态与转移，但阅读自动化函数不足以指导人工复验，
另写手册又容易与测试路径脱节。

## 结果

同一棵 BDD 状态树既可自动执行，也可仅输出结构；并列维护的 YAML 说明
让人按路径取得准备、命令、检查位置、预期现象及清理步骤。

## 边界

- 层次结构只有一份；说明采用稳定键关联，不从实现逻辑猜测操作步骤。
- 文档模式不运行测试、hook 或说明中的命令，不创建测试环境或启动服务。
- 先以 Check Host 验证；保持 Node Test 原有执行语义，不新增依赖式测试调度。

## 验收标准

1. 同一状态树可正常测试，也可输出终端树、Markdown 及可离线查阅的 HTML。
2. 人工手册可展开完整路径：父到子的准备、当前探针、子到父的清理；包含故障路径及平台限制。
3. 说明引用缺失或格式无效时明确失败；人工能依据手册复验 Check Host 代表路径，而不必阅读实现函数。
