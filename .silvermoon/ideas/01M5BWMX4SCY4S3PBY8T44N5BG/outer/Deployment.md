# Deployment

本契约是准备阶段的可调整初版，不授权 npm 发布或现有 Objective 定义的迁移。

## Steps

### D-S01: 验证实际跨目标治理

在受控试用环境以新版示例运行中间依赖，观察交接、外部治理与原目标恢复，记录可复现证据。

### D-S02: 确认手动迁移前置条件

真实工程切换前，确认当前工程与 Silvermoon 工程的定义已另行手动迁移；尚未完成时明确阻塞真实接入，不修改定义或添加兼容层兜底。

## Acceptance criteria

### D-AC01: 真实交接与恢复可观察

试用记录证明原目标 Agent 不代为治理依赖，外部目标达标后原目标重新观察并能继续。

### D-AC02: 切换边界可辨识

记录新问题协议成功、旧 prerequisite 字段及旧问题输出明确拒绝的结果；未变化的合法 Manifest 不应仅因历史存在而被拒绝。真实工程接入必须有单独手动迁移完成的证据，不能将样例成功当作两工程已迁移。
