# Implementation

## Steps

### I-S01: 明确接口与实施边界

依据[修改建议副本](./ideal/Recommendation.md)和 Idea 边界核对现有实现、数据形状及兼容性，不扩大至外部产品。

### I-S02: 落实改动与针对性回归

复用 readTaskArtifact 和现有 CLI，补齐同快照身份结果、可核实来源及上层发布前比较；通过复现定位缓存追踪问题再修复，不预设缓存产品根因。

## Acceptance criteria

### I-AC01: 改动满足本地契约

实现、文档和公开入口与本子 IDEA 的范围一致；未验证的根因和来源不被表示为已确认。

### I-AC02: 回归保持既有保护

对 CRLF/LF、旧缓存、同名旧副本和读后替换设计针对性回归，验证身份各字段来自同一次稳定读取。 适用的仓库检查通过，未降低既有约束。
