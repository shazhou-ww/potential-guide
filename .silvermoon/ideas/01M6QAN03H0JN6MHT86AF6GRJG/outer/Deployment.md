# Deployment

## Steps

### D-S01: 验证独立打包消费

在仓库外安装本次 tarball 及其依赖闭包，从公共入口构建/读取文本与 binary 样例，不引用源码或工作树模块。不发布 npm、不创建 Pinboard pin。

### D-S02: 验证跨平台内容身份

在 Windows 和 Linux 环境使用同一工具/配置，比较 LF/CRLF/CR 输入的规范文件及根 CID，验证同根不同容器和错根拒绝。环境不可用明确记录阻塞，不用模拟输入代替真实操作系统证据。

## Acceptance criteria

### D-AC01: 公共入口独立可用

打包消费者实际证明 manifest 自解释、文本规范化、binary 原样和旧契约拒绝；记录包/工具版本、命令、实际结果，不以仓库单测代替独立消费。

### D-AC02: 两端 CID 一致

Windows/Linux 独立消费回执证明同一规范内容根 CID 一致、合法不同容器无需哈希匹配、明确错根被拒绝。仅接受真实证据，不声称本地验证证明外部服务已 pin。
