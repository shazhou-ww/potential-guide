# 持续保持 Agent 开发机健康可用

## 问题

工具安装成功不代表开发机能长期使用；权限、系统资源、工具链和工作目录都可能随开发活动退化。目前缺少可重复观测、引导自主修复并复核结果的开发机健康目标。

## 结果

提供面向指定 Linux 环境和专用账号的持续健康 Pilot，让 Agent 在既定全面管理授权内自主维护，使设备保持可管理、系统可用、开发就绪、工作有序和持续健康。

## 边界

- 首版支持 Linux、WSL 内 Linux 和 Linux 容器，不管理原生 Windows 或容器／WSL 宿主；详见[管理范围与授权](./scope-and-authority.md)。
- 检查只观测和执行隔离验证，修复由 Agent 执行；全面管理授权不取消数据保护和可追溯要求。
- 四种技术栈按设备需求选择；健康采用累计、可退化的[五层标准](./health-levels.md)，不是一次性安装凭证。

## 验收标准

- 五层检查能定位偏离，明确区分不健康、无法检查和不适用，并在修复后重新判定。
- 所选技术栈能以指定账号实际构建和运行，正常工作负载及未提交成果不会被错误清理。
- 按 [Docker 验收要求](./docker-validation.md)，可重复证明健康通过、故障检出、修复恢复及隔离边界；真实 Linux／WSL 的差异另行验证。
