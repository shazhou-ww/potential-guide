# Implementation

本契约是准备阶段的可调整初版，构想验收不包含实施完成承诺。需求入口为 [Idea.md](./ideal/Idea.md)。

## Steps

### I-S01: 定义健康观测契约

结合现有 Pilot 能力确定 subject、五层累计判定、环境适用性、版本及阈值策略、证据有效期和诊断表达，不提前扩张通用协议。

### I-S02: 实现检查与维护指导

实现身份、系统、所选技术栈、工作秩序及趋势检查和对应指导，保持观测与修复分离，并说明与现有 setup Objective 的边界。

### I-S03: 建立可重复验证

增加隔离 Docker 夹具、故障注入及回归测试，覆盖正常、故障、修复恢复、再次退化和数据保护。

## Acceptance criteria

### I-AC01: 五层语义可验证

以针对性测试证明累计判定、适用性、故障分类、阈值边界和证据不足行为符合支持文档。

### I-AC02: 工具链与隔离边界有效

以 Docker 场景证明所选栈真实构建运行、故障准确定位、修复后恢复且不会损害受保护数据；保存可复现命令和结果。

### I-AC03: 仓库集成通过

Pilot 规范验证、相关回归及 `pnpm check` 通过；文档提供准确运行方式，并明确未完成的真实环境验证。
