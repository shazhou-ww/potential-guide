# 默认留存 check 与 probe 的本地 JSONL 证据

## 问题

check 与 probe 的最终结果不足以解释检查过程，临时证据又会随清理消失，失败后难以复核。

## 结果

默认按独立运行目录保留可关联的 JSONL 业务事实、原始结果与证据文件，让用户能够追溯检查内容、断言及未完成原因，并可配置留存位置。

## 边界

1. 保持现有 stdin/stdout 协议、结果语义与 `--report` 导出兼容；业务不通过不等同于执行失败。
2. 仅本地留存安全事实，不自动保存完整 subject、环境或凭据；不引入远程上传、OTel SDK 或自动清理。
3. 覆盖独立 check、probe 及相关内置、生成和打包运行入口；证据失败与截断必须显式可见。

## 验收标准

1. 默认及指定目录运行后，均可关联运行身份、检查尝试、业务步骤、原始结果与证据引用。
2. 成功、业务不通过、执行失败和中断可区分，无终止记录时不误判成功。
3. 相关入口保持兼容，目录隔离与安全边界有可重复验证的测试和使用文档。
