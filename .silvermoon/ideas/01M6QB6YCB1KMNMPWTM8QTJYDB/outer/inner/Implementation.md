# Implementation

## Steps

### I-S01: 明确接口与实施边界

依据[修改建议副本](./ideal/Recommendation.md)和 Idea 边界核对现有实现、数据形状及兼容性，不扩大至外部产品。

### I-S02: 落实改动与针对性回归

基于现有生命周期事实形成有界诊断投影，区分等待窗口、执行预算和释放未确认，并为三类现象分别构建复现入口。

## Acceptance criteria

### I-AC01: 改动满足本地契约

实现、文档和公开入口与本子 IDEA 的范围一致；未验证的根因和来源不被表示为已确认。

### I-AC02: 回归保持既有保护

注入启动阻塞、迟到退出及缺失确认，核对不提前写 reclaimedAt；正常路径诊断开销有界且不阻塞回收。 适用的仓库检查通过，未降低既有约束。
