# Deployment

## Steps

### D-S01: 独立验证实际消费结果

在当前 Bundle/Check 消费链路的适用 Windows/Ubuntu 与 Node CI 矩阵中回放可控案例，绑定候选包、提交和环境，保存失败身份及首轮/重试关联。退役 Probe 适配测试仅作历史来源；不以概率重跑或放宽预算替代回归。

## Acceptance criteria

### D-AC01: 结果有可复验证据

当前故障有可定位因果证据，配置拒绝、夹具窗口、业务预算及物理释放结论分别记录；已修原因由可控回归证明，未知原因仍明确未解决。真实退出/回收证明独立于日志；外部环境或授权不可用时报告阻塞。
