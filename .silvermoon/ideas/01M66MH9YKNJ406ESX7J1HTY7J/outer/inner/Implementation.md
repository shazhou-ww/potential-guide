# Implementation

以下为可调整准备种子；终结语义和兼容政策未定，不开始实施。

## Steps

### I-S01: 明确终结与兼容契约

根据理想世界决定定义时间匹配、终结层次及旧枚举和持久记录的兼容边界，
保留 Task 独立取消和期限、不扩大共享权限。

### I-S02: 对齐协议与使用入口

按已确定契约更新通用匹配、引擎结算、公开接口、使用文档与相关测试，
不在业务包另建时间匹配或状态真相。

## Acceptance criteria

### I-AC01: 时间适用规则一致

通过基于类型与 Input 且不依赖 Prepared 的事件时点绑定、边界时间、
执行失败、Task 取消、超时成功与超时失败及多 owner 用例，
证明接纳、结算和投影使用同一已定义语义，不误终止其他请求的共享执行。

### I-AC02: 兼容历史与公开调用

通过旧请求及持久记录回放、重启和公开接口回归证明兼容政策有效，
并通过相关打包验证与 `pnpm check`。
