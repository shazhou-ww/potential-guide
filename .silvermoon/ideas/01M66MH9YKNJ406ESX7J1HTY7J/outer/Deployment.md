# Deployment

仅为 preparing 种子，尚无外部验证或验收；由用户指定的父代理审查并续派。
后续仅在本工作树拥有的隔离目录验证准确制品，不包含 npm 发布或生产数据迁移。

## Steps

### D-S01: 验证独立消费者时间语义

以独立消费者调用准确打包制品，验证 start 与 terminate 时点绑定、完成、失败及单请求取消或超时，
并区分已接收 Task 与同时间戳后接收 Task，不使用源码内部状态代替公开证据。

### D-S02: 验证新存储与拒绝旧格式

以独立进程验证新格式幂等和重启、旧枚举请求拒绝及旧存储原样保留；
记录制品标识、公开错误和数据对比，结束后只清理本轮拥有的进程与验证目录。

## Acceptance criteria

### D-AC01: 外部结果符合终结契约

以公开结果和事件证明时间适用性符合接受的契约，成功或失败与超时可同时表达，
多 owner 不互相误终止；
记录准确制品及可复核输出，不将超时、取消或物理回收误报为成功。

### D-AC02: 升级边界与清理可证

以公开调用和独立进程证据证明新格式重启不重新锚定、旧格式明确拒绝并提示另用新存储，
旧数据未改写；记录自有验证资源清理结果，不触碰真实旧库或发布渠道。
